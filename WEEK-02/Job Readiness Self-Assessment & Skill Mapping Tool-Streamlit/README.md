# Job Readiness Self-Assessment & Skill Mapping Tool

A Streamlit-based application that helps individuals understand **how ready they are for a specific AI/data role**, identify **skill gaps**, and receive a **clear learning roadmap**.

This project was built as part of **Week 02 – Application Development (No Model)** of the HEC Generative AI Training Program.


##  Problem Statement

Many students and early professionals:
- Don’t know what skills a role actually requires
- Don’t know where they currently stand
- Feel lost before applying for jobs or starting learning paths

This tool provides:
- Structured clarity
- A measurable readiness score
- Actionable next steps


##  Solution Overview

The application performs a **deterministic skill-matching analysis**:

1. User selects a target role
2. User self-rates their skill proficiency
3. System compares inputs with predefined role requirements
4. Outputs:
   - Overall readiness score
   - Skills Fully Met
   - Skills Needing Improvement
   - Missing Skills
   - Prioritized Learning Roadmap

All results are **fully explainable**.


##  Key Features

- Role-based readiness assessment  
- Skill gap identification  
- Clear categorization: Fully Met / Needs Improvement / Missing  
- Priority-based learning roadmap  
- Exportable PDF assessment report  
- Hugging Face deployment ready
