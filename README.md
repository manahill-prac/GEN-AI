# Generative AI Learning Journey (HEC Training – Cohort 2)

This repository documents my structured learning journey through the **HEC Generative AI Training Program (Cohort 2)**.

The goal of this repository is to:
- Build strong foundations in Generative AI
- Progress step-by-step from fundamentals to real-world applications
- Develop deployable, explainable, and scalable GenAI systems

##  Learning Philosophy

This repository follows an **engineering-first approach**:

- Understand the problem before adding AI
- Build deterministic logic before models
- Add LLMs only where they create real value
- Focus on explainability and structure, not hype
